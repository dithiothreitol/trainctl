# Code of conduct

## The short version

Be decent to people. Argue with the claim, not the person making it.

## What that means here

- **Technical disagreement is welcome, personal attacks are not.** "This rule
  contradicts the source it cites" is the best kind of issue. "Only an idiot
  would plan a week like this" is not the same sentence.
- **Training talk stays respectful.** People arrive with different bodies,
  paces, ages, injuries and reasons for running. Nobody needs comments about
  their weight, their times or their choices.
- **Assume the other person read the docs and still disagrees.** Explain
  rather than dismiss.
- **No harassment**, in issues, pull requests or anywhere else this project is
  discussed: no slurs, no sexualised comments, no doxxing, no pile-ons.

## Enforcement

The maintainer moderates: unacceptable comments get edited or removed, and
repeat behaviour ends in a block. If something needs saying privately, email
the maintainer at the address in the git history rather than posting it.

Reports are handled as discreetly as one person can manage. There is no
committee here, and pretending otherwise would be dishonest.
